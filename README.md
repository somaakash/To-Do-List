# 📝 To-Do Application (JavaScript)

A simple and interactive **To-Do List application** built using **HTML, CSS, and Vanilla JavaScript**.  
This project helps users add, edit, mark as complete, and delete tasks in a clean UI.

---

## 🚀 Features

- ➕ Add new tasks  
- ✅ Mark tasks as completed  
- ✏️ Edit existing tasks  
- 🗑️ Delete tasks  
- 🎨 Simple and clean user interface  
- ⚡ Built using pure JavaScript (no frameworks)

---

## 🛠️ Technologies Used

- **HTML** – Structure of the application  
- **CSS** – Styling and layout  
- **JavaScript** – Logic and DOM manipulation
